# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected security or privacy problem.
Instead, use GitHub's private vulnerability reporting feature for this repository.

Include:

- The affected file or workflow
- Steps to reproduce
- The expected and observed behavior
- Any potential exposure of credentials or private information

## Data policy

This repository must contain fictional demonstration data only. Do not submit:

- Real customer, employee, supplier, SKU, price, or facility information
- Credentials, tokens, API keys, PIN hashes, or production configuration
- Inventory exports, backups, screenshots, labels, or operational documents
- Private repository URLs or internal planning material

All contributions are checked with gitleaks and a repository-specific public-safety
scanner.

## Supported version

Only the current default branch is supported. This is a static demonstration and not
a production warehouse system.
