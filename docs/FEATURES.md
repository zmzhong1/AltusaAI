# Demo Feature Coverage

The Minimal variant is the complete interactive demonstration. Tech and Warm are
visual studies that preserve the base inventory, map, dashboard, order-board, and
picking experience.

## Access and control

| Capability | Minimal |
|---|---|
| PIN keypad and cooldown | Working |
| Staff, Manager, and Admin roles | Working |
| Role-gated review, edits, refunds, and imports | Working |
| Production authentication and user administration | Not included |
